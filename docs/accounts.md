# Школы и доступ

Первый этап кабинетов, 27.09.2026. Работает локально; публикация в интернете ещё не подготовлена.

## Первый вход

1. Запустите `run_server_5001.bat`, откройте http://127.0.0.1:5001/setup.
2. Введите одноразовый код из `data/math9/_access/setup-code.txt`. Если страница открыта подготовленной ссылкой, код подставится автоматически.
3. Укажите имя, логин и собственный пароль длиной 12–128 символов. Не используйте пароль роутера.
4. После регистрации откроется «Школы и доступ». Код настройки удаляется и повторно не действует.

## Приглашение учителя

1. Добавьте реальную школу. Ожидаемое число бланков можно не указывать; это ориентир, а не квота. Количество школ не ограничено числом 30.
2. Выберите школу, укажите, кому предназначено приглашение, и создайте ссылку.
3. Ссылка одноразовая, действует 48 часов, показывается только при создании. При потере отзовите её в истории и создайте новую.
4. Учитель самостоятельно задаёт имя, логин и пароль. Школа закреплена приглашением, изменить её при регистрации нельзя.

Пока адрес начинается с `127.0.0.1`, ссылка работает только на этом ПК. Не отправляйте её коллегам до настройки внешнего HTTPS-адреса. После настройки передавайте каждое приглашение лично адресату: владелец ссылки может зарегистрироваться от имени приглашённого.

## Права

В форме новой работы координатор выбирает ОГЭ или ЕГЭ, математику или русский язык. Выбор сохраняется для каждой загрузки и отображается в списке. Старые работы показываются как ОГЭ по математике без перезаписи их файлов. Только этот существующий шаблон сейчас распознаётся; остальные направления принимаются как PDF со статусом ожидания настройки шаблона, без ответов и баллов. Учителям новые переключатели пока не доступны.

- Координатор видит все работы, добавляет школы, приглашает учителей, отключает доступ и отзывает неиспользованные приглашения.
- Учитель видит только собственные загрузки, даже если другой учитель относится к той же школе. Сканы, CSV, ключи и прямые ссылки подчиняются тем же правилам. Учитель может удалить свою работу, но корзина и восстановление доступны только координатору.
- Старые работы без владельца доступны только координатору. Ответы, изображения и статусы проверки не мигрируют и не перезаписываются.
- При отключении школы или пользователя прежние сеансы перестают действовать. Повторное включение требует нового входа.
- Вход действует до 8 часов бездействия. Есть ограничение частоты попыток входа и регистрации, защита POST-запросов от CSRF. Пароли и приглашения хранятся в базе в виде хешей.

Каждый PDF: до 100 страниц и 80 МБ. Школа может загрузить несколько файлов. Это не обещание обработки всех школ одновременно: OCR пока последовательный. Незавершённая очередь восстанавливается при запуске из метаданных, готовые страницы не перераспознаются. Работы с ошибкой всей обработки требуют ручного повтора. При свободном месте менее 5 ГБ загрузки отклоняются.

## Данные и обслуживание

В `data/math9/_access/accounts.sqlite3` находятся учётные записи, школы, хеши приглашений, постоянный секрет сессий и журнал действий с доступом. Журнал изменений ответов пока не реализован.

Корзина хранит работу 72 часа с момента удаления (для старых работ учитывается прежняя локальная дата). Затем удаляется вся папка работы: PDF, изображения, ключи и ответы. До истечения срока координатор может восстановить её. При штатном запуске через `serve.py` или `webapp.py` очистка выполняется сразу и далее каждую минуту, без посещения страниц пользователями. После выключения ПК просроченные работы удаляются при следующем запуске. При заблокированных файлах выполняется повторная попытка; повреждённые даты и ссылки/junctions пропускаются с записью предупреждения в журнал. Эксперименты и отдельные резервные копии не очищаются этим механизмом. Простой импорт `app` без запуска обслуживающего обработчика очистку не запускает.

При запуске через `serve.py` до начала обслуживания создаётся проверенная ZIP-копия `data/math9`, включая `_access`, в выбранном каталоге резервирования. Это не ежедневное резервирование: длительно работающий сервер нужно резервировать отдельно. Копии не зашифрованы; порядок хранения и восстановления описан в [deployment.md](deployment.md). Не удаляйте базу для «сброса пароля»: это потеря связей с владельцами работ.

Восстановление и смена паролей через интерфейс, дополнительная защита администратора и полный журнал правок относятся к следующему этапу. Пока сохраняйте пароль координатора в менеджере паролей.

## Настройки будущего размещения

- `MATH9_PUBLIC_URL`: заранее настроенный внешний HTTPS-адрес; используется для ссылок, не берётся из заголовка Host.
- `MATH9_HTTPS=1`: включать только при действующем HTTPS; устанавливает Secure для cookie. Сам по себе HTTPS не настраивает.
- `MATH9_SECRET`: необязательное переопределение секрета сессий. Без него используется постоянный случайный секрет из базы. Смена секрета завершает существующие сеансы.

Не публикуйте встроенный Flask-сервер и не пробрасывайте порт 5001 наружу. Waitress, восстановление очереди и копия при запуске уже добавлены. Внешний HTTPS включён для проверки кабинетов. Перед массовым доступом школ нужны изоляция PDF-обработки, лимиты ресурсов, регулярные резервные копии и испытание нагрузки. Настройка адреса провайдером не заменяет эти шаги.

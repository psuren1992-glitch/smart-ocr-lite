# Бланки для Android

**Автономный помощник учителя: сканирование, распознавание и сверка экзаменационных бланков.**

Версия `0.1.0-preview2`, 22 октября 2026 года. Это ранний тестовый выпуск, не готовый массовый продукт. Пользователь сообщил об успешном распознавании отсканированного файла в preview1. Это не полная приёмка: точность на рукописных работах с камеры пока не измерена, голосовой ввод и удаление из preview2 на телефоне ещё предстоит проверить.

## Скачать

[APK и инструкция в GitHub Releases](https://github.com/psuren1992-glitch/smart-ocr-lite/releases/tag/android-v0.1.0-preview2).

Android 8.0+ (API 26), 64-битный ARM-процессор. APK около 54 МиБ. Для iPhone эта версия не подходит. Сборка подписана отладочным ключом и предназначена для ограниченного тестирования. Проверяйте SHA-256 по файлу `SHA256SUMS.txt` из релиза.

## Для чего приложение

Учитель создаёт контрольную, фотографирует бланки либо выбирает готовые сканы, исправляет границы и запускает распознавание. Приложение показывает фрагменты бланка и прочитанные ответы, которые можно исправить вручную. Затем ключ ответов помогает сравнить ответы и посчитать баллы первой части.

Распознавание выполняется на устройстве. Модель и шаблоны включены в APK, сетевого разрешения Android `INTERNET` нет. Не нужны сервер, регистрация или загрузка модели при первом запуске. Системная камера и файловый менеджер являются отдельными приложениями; для строгого офлайн-теста выбирайте файлы из локальной памяти.

## Что реализовано

- Съёмка через установленную камеру телефона и импорт PDF/JPG/PNG.
- Автопоиск границ с ручной коррекцией четырёх углов, выправление перспективы, поворот, цветной/серый/чёрно-белый режим и контраст.
- Локальное распознавание по калиброванным шаблонам; ручная правка ФИО, варианта, кода школы и ответов.
- Кнопка микрофона рядом с ФИО: только встроенная офлайн-речь Android 12+, русский пакет на устройстве и подтверждение перед заменой поля. На остальных устройствах остаётся ручной ввод.
- Удаление одного листа или нескольких выбранных, с подтверждением. Исходные PDF/фото вне приложения не изменяются.
- Импорт ключа из CSV/XLSX или его ручное заполнение. Ключ не влияет на распознавание.
- Сравнение с ключом и баллы первой части только после ручного подтверждения сверки.
- Экспорт PDF с результатами и полными сканами, а также CSV для Excel.
- Сохранение работ в приватном хранилище приложения, оригинала после импорта отдельно от отредактированного изображения.

## Экзамены и задания

| Профиль | Задания для сравнения с ключом |
| --- | --- |
| ОГЭ математика | 1-19 |
| ЕГЭ математика, база | 1-21 |
| ЕГЭ математика, профиль | 1-12 |
| ОГЭ русский язык, пилот | 2-12 |
| ЕГЭ русский язык, пилот | 1-26 |

Поддерживаются конкретные шаблоны проекта, а не любые экзаменационные листы всех лет. В нашем сценарии поле **«Код региона» используется как номер варианта работы**; его нужно сверить и при необходимости исправить цифрами. Это соглашение приложения для тренировочных работ, а не изменение официальных правил заполнения экзамена.

Тип каждого листа выбирает человек. Для ЕГЭ: регистрация, ответы №1, затем дополнительные листы этого ученика. Листы №2 не распознаются и не считаются новыми учениками. Неопределённый тип листа блокирует экспорт, чтобы случайно не пропустить лист.

## Голосовой ввод и удаление

На экране сверки нажмите микрофон рядом с ФИО, предоставьте доступ к микрофону и произнесите имя. Приложение покажет результат для правки и подтверждения; до «Подставить» поле не меняется. После замены нужно заново подтвердить сверку и сохранить. Отмена, ошибка или отказ в разрешении не стирают прежнее ФИО.

Используется только `SpeechRecognizer.createOnDeviceSpeechRecognizer`, не общий сетевой распознаватель. Нужны Android 12+ и поддержка русского офлайн-ввода конкретным телефоном. На Android 13+ проверяется установленный языковой пакет, если системная служба поддерживает эту проверку. Если функция недоступна, приложение сообщает об этом, не переключается в облако и не загружает модели. Разрешение `RECORD_AUDIO` запрашивается только при нажатии кнопки; аудиофайлы приложение не сохраняет. См. [API Android](https://developer.android.com/reference/android/speech/SpeechRecognizer#createOnDeviceSpeechRecognizer(android.content.Context)).

Откройте лист и нажмите «Удалить этот лист» либо в работе выберите «Выбрать и удалить листы». Можно отметить несколько или все листы; перед удалением показывается список и отдельное подтверждение. Удаляются внутренние сканы, фрагменты и правки выбранных страниц. Удаление необратимо; внешние PDF/фото и ранее сохранённые экспорты не меняются. При удалении всех листов остаются название работы и ключ.

Если после удаления изменилась предшествующая регистрация ЕГЭ, прежние ответы/ФИО сохраняются, автоматическое копирование данных другой регистрации отключается, а экспорт требует подтверждения принадлежности. Дополнительные листы с изменившимся окружением нужно просмотреть заново.

## Важные ограничения

- Пилот ещё не прошёл полную приёмку на телефоне. Скорость, память, качество ФИО и рукописных букв не измерены на репрезентативном наборе.
- Это не полный перенос движка ПК: используется базовая модель PaddleOCR в ONNX, без серверного ансамбля и дообученной модели ФИО.
- Нижние замены ответов переносятся вручную. Автоматического определения комплектов, live-сканирования с автоспуском и серии снимков пока нет.
- Развёрнутые ответы проверяет учитель. Общий балл с ручной второй частью и итоговая отметка в мобильной версии ещё не реализованы.
- Нет защищённого обмена `.blanki`, синхронизации, рассылки и многолетнего реестра учеников. PDF/CSV нельзя импортировать обратно как редактируемый проект.
- Маска: CSV UTF-8 или простая XLSX-книга с одним листом. Читается физический `sheet1.xml`; старые XLS и формулы не поддерживаются. Ведущие нули в ключе храните текстом.
- До 100 страниц на работу; PDF до 80 МиБ, изображение до 40 МиБ. Начните тест с одного листа, а не большой пачки.

## Данные и безопасность

Все поля, включая ответы с высокой уверенностью OCR, необходимо сверять. Не используйте неподтверждённые ответы для выставления оценок.

Системное резервное копирование и перенос приватных данных отключены в настройках приложения. Удаление приложения или очистка его данных удалит работы. Не храните единственные копии важных документов в тестовой сборке.

Обновление preview1 -> preview2 устанавливайте поверх существующего приложения. У опубликованных APK совпадают пакет и сертификат подписи, `versionCode` увеличен с 1 до 2. Существующий формат работ совместим, распознавание повторно не запускается. Не удаляйте приложение перед обновлением; обновление с данными на настоящем устройстве ещё требует проверки.

PDF/CSV **не зашифрованы** и могут содержать персональные данные. Передавайте их только нужным адресатам, не публикуйте в Issues, открытых репозиториях или общедоступных ссылках. Для сообщения об ошибке используйте пустой бланк или искусственный пример.

## Сборка из исходников

Потребуются JDK 17 и Android SDK Platform 36. Сетевой доступ нужен компьютеру для первоначальной загрузки Gradle и библиотек, но не установленному приложению.

```powershell
cd apps/android
# JAVA_HOME должен указывать на JDK 17, ANDROID_HOME на Android SDK.
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Для Linux/macOS: `bash gradlew assembleDebug testDebugUnitTest lintDebug`.

APK: `app/build/outputs/apk/debug/app-debug.apk`. При сборке на другом компьютере будет использован его debug-ключ; такая сборка может не обновить установленный APK из релиза. Не удаляйте приложение с единственной копией работ ради смены подписи.

Версии: Gradle 8.14.3, AGP 8.11.0, compileSdk 36, targetSdk 35, minSdk 26, ARM64. OpenCV 4.12.0, ONNX Runtime Android 1.23.2, AndroidX Core 1.16.0, ExifInterface 1.4.1. Модель, алфавит и геометрия входят в исходники; происхождение модели и SHA-256 записаны в `model-manifest.json`.

## Устройство кода

Java-код находится в `app/src/main/java/ru/blanki/mobile/`.

| Файл | Задача |
| --- | --- |
| MainActivity.java | Экраны, импорт, камера, фоновая обработка и сверка |
| ImageTools.java, CropView.java | Работа с изображением, границы и перспектива |
| Ocr.java | Четыре метки, фрагменты и ячейки, вызов ONNX, чтение символов |
| Profile.java | Диапазоны заданий и сравнение с ключом |
| MaskReader.java | CSV/XLSX с ограничениями размера и без выполнения формул |
| Store.java | UUID работ и листов, приватные файлы, атомарный JSON |
| PageActions.java | Выбор страниц и отдельное подтверждение удаления |
| PageEdits.java, PageDeletion.java | Удаление по UUID, контроль связей ЕГЭ, сохранение нового JSON до очистки файлов, повтор незавершённой очистки |
| NameVoiceInput.java, VoiceNames.java | Жизненный цикл офлайн-речи, разрешение микрофона, подтверждение и минимальная очистка результата без словарной подмены |
| Exports.java | Проверка готовности, PDF и CSV |
| QaChecks.java | Debug-проверки на пустом эталоне и синтетических данных |

Поток данных: камера/PDF -> оригинал -> исправленный скан -> метки -> фрагменты -> OCR -> ручная сверка -> ключ -> экспорт. Перераспознавание требует подтверждения и сбрасывает сверку; перестановка листов тоже требует повторной сверки.

## Проверки этого выпуска

- 46 JUnit-тестов: пройдены, без пропусков. Новые тесты проверяют удаление, сбои сохранения/очистки, защиту путей, принадлежность листов ЕГЭ и подготовку текста ФИО.
- Android Lint: 0 ошибок, 5 предупреждений при чистой офлайн-сборке; онлайн-проверка дополнительно сообщает об обновлениях зависимостей. Остались вопросы доступности пользовательских View, целевого SDK и ABI; массовая готовность не заявляется.
- Подпись APK v2, выравнивание упаковки и 16-КиБ выравнивание сегментов четырёх native-библиотек проверены.
- На ПК проверены четыре пустых шаблона: метки найдены, ложных заполненных строк не обнаружено. Скрипт: `tools/verify_templates.py` (зависимости: PyMuPDF, OpenCV, NumPy).
- Преобразование Paddle -> ONNX: на трёх тестовых входных размерах argmax совпал; максимальная абсолютная разница около 2.44e-6. Это не оценка точности рукописного OCR.
- Модель ONNX и алгоритмы OCR в preview2 не менялись. Проверки шаблонов и конвертации выше относятся к базовой модели preview1.
- Есть положительный отзыв пользователя о распознавании готового скана. Полный сценарий камеры, голоса, удаления, обновления с данными, XLSX и экспорта на телефоне ещё не прошёл приёмку.
